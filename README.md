# Aishwarya Srivastava · Portfolio

Source for **https://1998-aish.github.io**, my portfolio website.

- `index.html`: the whole site (no build step, no framework)
- `assets/img/`: project charts, generated in each project's repository

To update a project, edit its `<article class="project">` block in `index.html` and push to `main`. GitHub Pages republishes automatically.
